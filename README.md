# Projeto Mousse 🍫

O **Projeto Mousse** é uma aplicação web desenvolvida para otimizar e facilitar a venda de doces no ambiente escolar. O sistema conecta alunos vendedores a potenciais clientes (colegas e professores), agilizando pedidos, controle de estoque e organização das vendas de forma prática e digital.

## 🚀 Tecnologias Utilizadas

Este projeto foi construído utilizando as seguintes tecnologias e ferramentas:

* **Front-end:**

  * **React:** Biblioteca JavaScript para construção da interface de usuário de forma componentizada.

  * **CSS:** Estilização responsiva e moderna para garantir uma boa experiência visual.

* **Back-end:**

  * **PHP:** Linguagem de script do lado do servidor responsável por gerenciar as requisições e a lógica de negócios.

* **Banco de Dados:**

  * **SQLite:** Banco de dados leve baseado em arquivos, gerenciado através de consultas SQL puras para persistência dos dados (pedidos, produtos e usuários).

## 📦 Funcionalidades

* **Catálogo de Doces:** Visualização dos doces disponíveis (como mousses, bolos de pote, etc.) com fotos, descrições e preços.

* **Carrinho e Pedidos:** Facilidade para montar o pedido e enviá-lo diretamente pelo sistema.

* **Painel de Controle (Back-end):** Gerenciamento simples de produtos e acompanhamento de vendas utilizando SQLite.

## 🛠️ Como Executar o Projeto

### Pré-requisitos

Certifique-se de ter instalado em sua máquina:

* [Node.js](https://nodejs.org/) (para rodar o React)

* Um servidor local com suporte a PHP (como XAMPP, WampServer ou o servidor embutido do PHP)

### 1. Configurando o Back-end (PHP e SQLite)

1. Clone este repositório ou baixe os arquivos.

2. Mova a pasta do back-end para o diretório do seu servidor PHP (ex: `htdocs` do XAMPP).

3. Certifique-se de que a extensão SQLite esteja habilitada no seu arquivo `php.ini`.

### 2. Configurando o Front-end (React)

1. Abra o terminal na pasta onde está o código do React.

2. Instale as dependências executando:

   ```
   npm install
   
   ```

3. Inicie o servidor de desenvolvimento:

   ```
   npm start
   
   ```
